# Too Many Bones Solo Academy

A research-led, multi-page solo play guide for **Too Many Bones**. This is an independent fan-made learning resource and is not affiliated with Chip Theory Games.

## Website

Once GitHub Pages is enabled and the first deployment succeeds, the expected URL is:

https://jamspot.github.io/too-many-bones-solo-academy/

## Structure

- `index.html` — homepage and navigation
- `getting-started.html` — first solo session learning path
- `rules.html` — rules reference topic map
- `gearlocs.html` — character dossier framework
- `tyrants.html` — Tyrant and Baddie research framework
- `expansions.html` — collection register
- `solo-strategy.html` — solo strategy and experiment plan
- `research.html` — source hierarchy and progress register
- `assets/style.css` — responsive light theme
- `assets/site.js` — accessible mobile navigation

## Research standards

1. Treat official rulebooks, reference sheets, FAQ and errata as the authority for rules.
2. Separate confirmed rules from strategic recommendations and untested hypotheses.
3. Record scope, edition, source and page/section for rules questions.
4. Cover the full owned collection, including expansions, Gearlocs, promos and accessories.
5. Avoid reproducing complete rulebooks or card text; summarise and cite official sources.

## GitHub Pages

The site uses plain HTML, CSS and JavaScript and does not require a build framework. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`. Alternatively, add a workflow-based deployment after repository Pages permissions are configured.

## Current status

The initial navigation and learning scaffolding are in place. The detailed rules, full roster, expansion inventory, Tyrant dossiers and tested solo recommendations remain research work and should not be treated as complete.
