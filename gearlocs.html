Gearloc academy

Individual dossiers will explain each Gearloc's official components and abilities, then separate rules from practical solo-piloting advice.

Official source first: CTG provides a reference sheet for each supported Gearloc on its Too Many Bones support hub. Use the sheet for that Gearloc alongside the correct game rulebook. The official base-game product page lists Picket, Patches, Boomer and Tantrum as its original four Gearlocs.

Current first-learning party

Picket

Part of the original base-game roster. His official reference sheet is linked from the CTG support hub. The academy has not yet published a full skill-by-skill build guide, so no specific build is being presented as established.

Patches

Part of the original base-game roster. CTG's FAQ confirms that Patches does not need to be adjacent to a Gearloc he heals. That is a specific Patches clarification, not a general range rule.

Read the official Patches healing clarification ↗

Why this pair? Picket + Patches is the provisional teaching pair already selected for the first learning game. This is a practical starting recommendation, not an official CTG-required combination, not a claim that it is the strongest pair, and not yet a table-tested result. We will keep the pair unless official setup requirements or the user's chosen content make it unsuitable.

What every dossier will contain

Official profile

Correct reference sheet, starting stats, innate ability, skill trees, dice and any expansion-specific component notes.

Rules clarifications

Only relevant CTG FAQs, errata and official clarifications, linked to the original publisher source.

Solo plan

Party-size assumptions, development priorities, encounter approach and Tyrant preparation. These are recommendations, not rules.

Testing record

Opening plan, milestone decisions, common errors and recorded results. Untested advice remains labelled as a hypothesis.

How recommendations are labelled

  • Official rule: supported by CTG rule text, reference sheet, FAQ or errata.
  • Strategy recommendation: the academy's analysis of official rules; not a publisher ruling.
  • Table-tested: supported by recorded play under stated conditions.
  • Hypothesis: an idea that still needs testing.
